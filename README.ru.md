# YM Overlay

[English](README.md) · **Русский**

Небольшой оверлей-контроллер для [YouTube Music](https://music.youtube.com), который всегда лежит поверх других окон: кнопки управления, прогресс-бар, громкость, очередь и ваши плейлисты в компактном окне без рамки.

Официальный API YouTube не используется. Приложение открывает настоящий `music.youtube.com` в обычном окне и управляет им, читая страницу и нажимая её кнопки. Аккаунт, подписка и настройки работают так же, как в браузере.

> **Неофициальный проект.** Не связан с Google и YouTube, не одобрен и не спонсируется ими. «YouTube» и «YouTube Music» — товарные знаки Google LLC. Приложение зависит от разметки страницы YouTube Music, поэтому редизайн сервиса может сломать часть функций (см. [Известные ограничения](#известные-ограничения)).

## Возможности

- **Управление воспроизведением** — предыдущий / следующий трек, пауза/старт (клик по обложке), ±15 секунд.
- **Прогресс-бар** с перемоткой, прошедшее и оставшееся время.
- **Громкость** — наведите курсор на среднюю группу кнопок, появится ползунок; уровень сохраняется между запусками.
- **Очередь** — текущий трек, несколько уже сыгранных перед ним и следующие за ним; клик по строке переключает на трек, в меню `…` можно добавить трек в один из ваших плейлистов.
- **Плейлисты** — плейлисты из боковой панели YouTube Music, у каждого два способа запуска:
  - **Shuffle** — вперемешку;
  - **Play sequentially** — по порядку, с первого трека.
- **Закрепление** — держать оверлей поверх всех окон или позволить другим окнам его перекрывать.
- Окно без рамки, прозрачное, перетаскиваемое.

## Требования

- **Windows 10 / 11** с [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (в актуальных версиях Windows уже есть).
- Аккаунт YouTube Music (бесплатный или Premium).

Другие платформы не проверялись, часть кода специфична для Windows/WebView2.

## Установка (из релиза)

1. Скачайте установщик на странице [Releases] и запустите его.
2. Запустите **ymoverlay**. Откроются два окна: окно **YouTube Music** и маленький **оверлей** поверх него.
3. Войдите в YouTube Music в первом окне (только в первый раз — сессия сохраняется приложением).
4. Включите любой трек. Оверлей следует за плеером.

**Не закрывайте окно YouTube Music** (его можно свернуть или спрятать за другими окнами). Это и есть настоящий плеер: если закрыть его, музыка остановится, а оверлею будет нечем управлять.

## Использование

| Действие | Как |
|---|---|
| Пауза / старт | клик по обложке |
| Предыдущий / следующий | боковые кнопки |
| ±15 с | две круглые кнопки со стрелками |
| Громкость | навести на среднюю группу кнопок, ползунок |
| Перемотка | потянуть прогресс-бар |
| Очередь | кнопка-стрелка справа внизу |
| Плейлисты | кнопка со списком слева внизу; `…` у строки → Shuffle / Play sequentially |
| Добавить трек из очереди в плейлист | `…` у строки очереди → Add to Playlist |
| Двигать окно | тянуть за название/исполнителя, поля карточки или край окна |
| Закрепить поверх окон | значок булавки справа вверху |

## Сборка из исходников

Нужны: [Node.js 18+](https://nodejs.org), [Rust (stable)](https://www.rust-lang.org/tools/install) и [зависимости Tauri для Windows](https://v2.tauri.app/start/prerequisites/) (Visual Studio Build Tools с компонентом «Разработка классических приложений на C++»).

```bash
npm install

# иконки приложения (любой PNG 1024x1024) — нужны для production-сборки
npx tauri icon path/to/logo.png

# запуск в режиме разработки
npm run tauri dev

# сборка установщика (результат: src-tauri/target/release/bundle/)
npm run tauri build
```

Стек: [Tauri 2](https://tauri.app) (Rust) + React 18 + Vite + Tailwind CSS.

## Как это работает

Приложение состоит из двух окон Tauri:

| Окно | Что показывает | Роль |
|---|---|---|
| `main` | настоящий `music.youtube.com` | плеер и ваша сессия |
| `overlay` | React-интерфейс этого проекта | компактный контроллер |

При старте в `main` внедряется скрипт (`src-tauri/scripts/ytm-watcher.js`). Он читает страницу (трек, таймер, очередь, плейлисты из боковой панели) и присылает изменения в оверлей как события Tauri. Команды идут в обратную сторону: оверлей собирает небольшие JavaScript-фрагменты (`src/lib/ytmBridge.js`) и отправляет их в `main` через команду `ytm_eval`, где они нажимают те же кнопки, что и вы.

Подробная архитектура и список найденных багов с их исправлениями — в [`PROJECT_MAP.md`](PROJECT_MAP.md).

## Известные ограничения

- **Зависимость от разметки YouTube Music.** После обновления сервиса селекторы могут перестать работать. Хрупкие места перечислены в `PROJECT_MAP.md`.
- **Play sequentially на секунду открывает страницу плейлиста** в окне YouTube Music (только там есть кнопка Play «по порядку»), запускает его и возвращается на прежнюю страницу. Чтобы остаться на странице плейлиста, выполните в DevTools этого окна `window.__ymoverlay.returnAfterSequential = false`.
- В списке только те плейлисты, которые YouTube Music показывает в боковой панели (до 30).
- Клик по уже играющему плейлисту может поставить его на паузу (штатная кнопка Play в YouTube Music работает как переключатель).
- Очередь показывается окном вокруг текущего трека, а не целиком.
- macOS и Linux не проверялись.

## Если что-то не работает

- **Оверлей показывает «Nothing playing»** — включите трек в окне YouTube Music и убедитесь, что вы вошли в аккаунт.
- **Ничего не реагирует** — проверьте, что окно YouTube Music не закрыто.
- **Диагностика** — в DevTools окна YouTube Music `window.__ymoverlay.enableDiagnostics()` пишет долгие задачи и дрейф таймера; в DevTools оверлея `window.__ovDiag.enable()` пишет задержки скролла и ввода.
